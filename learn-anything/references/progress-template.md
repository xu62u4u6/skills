# 進度檔範本（PROGRESS.md）

放在該科目學習 repo 的根目錄。每次學習結束時更新；開場時先讀。

```markdown
# 學習進度：<科目>

更新：YYYY-MM-DD

## 現在的位置

**上次停在：** <一句話>
**下一步只做：** <一件事>
**今天的目標：** <例如：理解 GAN、Diffusion、Flow Matching 的訓練與生成>

## 觀念狀態

| 觀念 | 狀態 | 證據 |
|---|---|---|
| <觀念> | 知道名字／能說明／能做出來 | <他的回答或程式，附日期> |

## 還沒回答的題目

1. <題目>（YYYY-MM-DD 提出）

## 停車場（之後再談的支線）

- <支線>：<為什麼先不談>

## 常見混淆（需要再測）

- <例：把「帶雜訊的圖」當成 y_true> → 下次用新例子再確認一次
```

## 狀態定義

- **知道名字**：聽過、能說出名稱。
- **能說明**：能用自己的話說出它在做什麼、為什麼需要。
- **能做出來**：能自己寫出程式、算出例子，或在新情境中正確使用。

只有「能做出來」才算掌握。
